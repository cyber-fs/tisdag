# Kurs AS20 – Frans (Vinter 2025)

Detta repository innehåller arbeten och övningar för kursen **Applied Script 20 YH (AS20)** under **Vinter 2025**.  
Arbetet demonstrerar praktisk tillämpning av scripting, versionshantering och systemadministration i **Linux-miljöer**.

---

## Översikt

| Projekt | Beskrivning |
|------------------|-------------|
| **Ö1** | **Script för informationsinsamling (Recon) i Linux**  |
| **Ö2** | **MD5 Hash Checker och knäckning med Hashcat**  |
| **Ö3** | **AV/EDR Malware Test i Windows-miljö**  |
| **BASH Script** | **Super Scanning Tool**  |

---

## Syfte / Mål

Målet med kursen är att ge en grundläggande förståelse för **automatisering, Bash och scripting**, samt hur scripting kan användas för att förenkla uppgifter och effektivisera arbetsflöden.

De huvudsakliga mål som uppnåtts i detta arbete inkluderar:

- **Bash Scripting och automatisering**  
  Förstå grunderna i Bash samt hantering av filer och kataloger i Linux med kommandon såsom `ls`, `cd`, `mkdir`, `touch` och `rm`.

- **Linux-systemkompetens**  
  Förstå och kunna ändra fil- och katalogbehörigheter med `chmod`, samt ha kännedom om Linux filsystemhierarki (FHS).

- **Versionshantering**  
  Introduktion till Git och GitHub för versionshantering och kodarbete, inklusive användning av `git add`, `git commit`, `git push` samt publicering av projekt på GitHub.

- **Multipla scriptingmiljöer**  
  Arbeta med scripting i olika miljöer, främst **Bash (Linux)** och **Python**.

- **Felsökning (debugging)**  
  Använda grundläggande felsökningstekniker i Bash, exempelvis `echo`, `set -x` och `set -e`.
